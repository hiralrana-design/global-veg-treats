# Bake Me Happy — Modern Bakery & Cafe

A warm, single-page website for a home-style bakery. Handcrafted cakes, dessert tacos, and fresh-baked breads — made with real butter and zero shortcuts.

## What's inside

- `index.html` — the complete website (HTML + CSS + JS in one file)
- `README.md` — this file
- `package.json` / `vite.config.ts` — minimal Vite setup for local preview

## Run locally

```bash
bun install
bun run dev
```

Then open `http://localhost:8080`.

## Publish to GitHub

This project is ready to be pushed to GitHub and published as a static site via **GitHub Pages** or any static host.

### Quick GitHub Pages setup

1. Push the project to a GitHub repository.
2. In the repo, go to **Settings → Pages**.
3. Under **Source**, select **Deploy from a branch** and choose **main** with the `/ (root)` folder.
4. GitHub Pages will serve `index.html` at `https://<your-username>.github.io/<repo-name>/`.

> **Note:** The live site is contained in the single `index.html` file, so it works on any static host without a build step.
